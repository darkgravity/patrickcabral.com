Cypher

PracticeAlgorithmic typography tool
ArtistPatrick Cabral
SeriesTechsugi

An algorithmic tool that automatically arranges and resizes text into dynamic layouts. Its letterforms adapt fluidly while preserving the continuity of their curves.

Originally developed to conceal messages within symbolic art, Cypher explores how language can become a changing visual structure. A version for Baybayin is currently in development, extending this research into a different writing system.
