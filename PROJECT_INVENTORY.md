Separate JPEG web copies under `docs/assets/manaoag` use maximum dimensions of 2,000 pixels for full images and 720 pixels for thumbnails, at quality 85; the original PNG files remain untouched. The supplied Topographical Beads image matches existing asset ID 22 (`art/346657.png`, also found as `techsugi/ribbon/yeastF.png`), so it does not require a new asset. The website uses optimized images, thumbnails, and films under `docs/assets`; raw images, source films, and full image sequences are not part of the publication.

Excluded: `art/346637.png` (ID 20), a blank opaque white image. The Techsugi Bone sequence is represented by selected angles instead of all 56 frames; duplicate Fiber and patterned-figure files are not repeated. `techsugi/1.png` depicts a layered blue feline and is held out of Lab until its physical-work versus digital-study classification is confirmed.

The artist portrait `art/artist.JPG` is included in the Starbucks project and reused in the About section. `scripts/prepare-previews.py` refreshes lightweight derivatives for the full manifest from existing web copies, and `scripts/prepare-assets.py` invokes it after processing the original artwork set. Original source files are unchanged. Preserve existing asset IDs when adding or regenerating media.
